# Что это?

sed-регулярки

Используется extended-версия (см. `man sed` или `man grep`)

```bash
sed -E -f sed_1.sed -f sed_2.sed your_file.txt
```

# А что внутри?

## sed_expr

Предназначен для конвертирования текстового файла в tex

* Экранирование нижних подчёркиваний: `_ → \_`.

* Дефисы внутри слов заменяются на `"=`.

* Набор пробелов (в том числе неразрывных) *в начале строки*, после которых идёт дефис, короткое или длинное тире, заменяется на `"--*`.

* Набор пробелов (в том числе неразрывных) *не в начале строки*, после которых идёт дефис, короткое или длинное тире, а после — пробел, заменяется на `\~"--- `.

* Инициалы вида `А.Б.` или `А. Б.` заменяются на `А.\,Б.`.

* Однобуквенные слова прицепляются к последующим неразрывным пробелом.

* Символ многоточия `…` заменяется на `...` (по TeXническим причинам).

* Набор из звёздочек `* * *` заменяется на `\textstars` (определена в `fbs.cls`).

## sed_fanfics_me

* CRLF -> LF.

* Неразрывные пробелы заменяются на обычные (так как они постом поставятся в нужных местах с помощью `sed_expr.sed`).

* Первая строка оборачивается в `\fbssection{}` (см. `fbs.cls`):

```sed
1s/^(.*)$/\\fbssection\{\1\}/g
```

После этого перед `}` остаётся переход на новую строку. Убираем его с помощью
```sed
1{N;s/\n}/}/}
```
